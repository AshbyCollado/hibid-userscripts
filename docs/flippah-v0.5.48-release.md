# Flippah 0.5.48

## Approved Branding

The owner selected the first October 5, 2026 draft and requested immediate
release: a blue rounded square with a green quill flowing into an upward arrow.
`assets/icons/flippah-source.png` retains that exact selected raster. The
16, 32, 48, and 128 pixel PNGs are mechanical exports, not a new interpretation.
Both browser manifests use these exports for toolbar and extension icons.

This is an icon-only update over 0.5.47. Research, fee math, storage, permissions,
and native auction controls are unchanged. Historical reference icons remain
archived and are not current build inputs.

## Verification And Delivery

Branding regressions check dimensions, RGBA transparency, manifest references,
and byte-identical assets in both generated browser packages. On October 5,
2026, typecheck and both development builds passed; the complete suite had
2,491 passes, two existing skips, and zero failures. The normal local
release command requires the complete suite and Store package validation before
upload. Upload/submission receipts are retained under
`artifacts/chrome-web-store`; submission, publication, and installed delivery
remain separate states. No new installed Waterfox acceptance is claimed.
