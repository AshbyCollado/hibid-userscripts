# Flippah 0.5.49

Restores compatibility with HiBid's redesigned catalog, search, lot and account
pages while retaining the approved branding and existing saved settings.

- Shared DOM adapter for tile, condensed, full and detail layouts.
- Immediate Amazon and eBay Sold/Completed links during research.
- Stable calculator placement, draft/focus preservation and scoped bid math.
- Correct catalog category filtering and promotional-result exclusion.
- Complete account pagination with bounded background-page cleanup.
- Selected-auction history exports, explicit scope and popup reopening recovery.
- Cancellation/retry and stale-popup-render regression fixes.

Actual Chrome verification and known limits are recorded in
`flippah-v0.5.49-redesign-acceptance.md`. No new permissions, auction mutations,
off-store updater, or separate-project import were introduced.

Local acceptance is not Store publication. The local release receipt and live
Store API are authoritative for submission/review/publication status.
